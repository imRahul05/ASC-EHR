## Commit 1 — `fix(api-client,mocks): align GET /worklist response shape (C1)`
**Bug:** Fastify returns `{ items, total }`, but MSW and `@asc/api-client` expect `WorkItem[]`. `worklist-view.tsx` then crashes with `all.filter is not a function` when it talks to the real API.
**Fix (canonical shape = `{ items: WorkItem[]; total: number }`):**
1. `packages/types/src/clinical.ts`: add `export interface WorklistPage { readonly items: readonly WorkItem[]; readonly total: number }`.
2. `packages/api-client/src/clinical/center.ts`: change `getWorklist` to return `Promise<WorklistPage>`.
3. `packages/api-client/src/react/hooks.ts`: `useWorklist` must use `select: (page) => page.items`, or update every consumer.
4. `apps/web/src/mocks/handlers/clinical/center.ts`: return `HttpResponse.json({ items, total: items.length })`.
5. Check any dashboard widget that calls `getWorklist` (`grep -rn "getWorklist\|useWorklist" apps packages`).
6. Add a test asserting that the shapes are identical in `apps/api/src/routes/worklist.test.ts` and in an MSW handler test.
